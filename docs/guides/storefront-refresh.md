# 商品列表与详情页改造交付（2026-11-13）

## 访问与运行

在 `frontend` 目录运行 `npm run dev`，使用 Vite 输出的本地端口：

- 列表：`/#/catalog`。
- 详情：`/#/products/{真实商品ID}`。
- 购物车与现有结算入口：`/#/cart`。
- 本次验收启动的前端地址：`http://127.0.0.1:5180/#/catalog`。真实模式需启动现有后端；开发代理默认指向 `http://localhost:8081`，通过 `VITE_API_PROXY_TARGET` 覆盖。

默认使用真实接口和原有登录规则。独立预览可设置 `VITE_DEMO_MODE=true` 后重启 Vite；演示数据集中在 `src/api/catalog.ts`，界面显示演示标记，加购只影响内存，不会产生真实交易。未改动项目的真实模式默认值。

## 实现内容

- 列表与详情复用 `ShopHeader`，使用浅灰背景、白卡片和砖红强调色，桌面内容限制为 1240px；保留商城外已有页面布局。
- 分类来自 `/categories`；关键词、分类、价格范围和排序组合传递到服务端。价格升降序清楚显示；重置页码、越界页修正、总数、分页、单页隐藏分页、已选条件清除及空状态均已接通。
- 保留搜索联想；列表请求及联想请求通过序号隔离过期响应。
- 查询写入 URL；详情链接保留完整列表来源，返回后恢复查询、页码和当次会话的滚动位置。
- 商品图片为正方形并完整展示，支持缺图和错误占位；首行优先加载，其余按需加载。标题两行、统一人民币价格、不展示“已上架”管理状态或零销量，不添加原价、评分或服务承诺。
- 详情包含图片切换和原生模态放大预览，支持 Escape、方向键、焦点恢复，展示真实介绍、属性、服务信息和已有评价汇总。介绍沿用文本插值，不执行接口内容中的 HTML。
- 规格选项依据真实 SKU 组合禁用；选中后更新价格、库存和主图。数量按正整数、库存及现有购物车 999 件上限校验。
- 普通商品接入真实加购，沿用登录跳转与后端幂等键，提交中禁用重复点击；直接采用写接口返回的购物车数量，避免“写入成功但刷新失败”被误报成加购失败。商品 ID 保留字符串，避免 Java Long 转换损失精度。
- 手机使用可展开价格筛选和详情固定购买栏，适配底部安全区域；详情隐藏原有底部导航，预留购买栏空间。
- 后端商品卡片新增 `skuCount`，直接从真实 SKU 表计数，无数据库迁移。旧服务没有该字段时，加购前读取详情以确认商品模型。

## 尚待接通的真实业务能力

**SKU 商品暂不支持购买，包括采用 SKU 模型的单规格商品。** 现有商城可读 SKU 价格与库存，但 `CartAddRequest`、`cart_item`、订单明细及库存预占仍只按商品 ID 工作。页面已完成规格选择与展示，并明确提示暂不支持在线购买；没有发送会丢失所选规格的加购请求，也没有模拟交易成功。

后续需要统一提供并实现：

1. SKU 加购契约、购物车项持久化、同商品不同 SKU 的合并规则。
2. 购物车和订单中的 SKU 名称/参数快照及真实 SKU 成交价。
3. SKU 库存校验、锁定、扣减、取消释放与支付后的库存处理。
4. SKU 或商品的实际限购规则及对应 API 字段（目前只有现有购物车 999 件上限）。

现有结算会处理购物车中的选中商品，因此详情使用“查看购物车，去结算”，未增加会误结算其他选中商品的“立即购买”。真实支付、生产数据和真实账号下的完整交易尚未进行端到端验收。本次没有部署上线，也没有改写真实业务记录。
