# 登录模块优化

## 页面与交互

沿用微信原生页面、现有消费者会话和 Spring Boot API，没有新增依赖、接口或演示数据。

- `pages/login/index.wxml`：品牌区、登录卡片、手机号与密码标签、注册入口、微信登录、游客浏览及登录帮助。登录、注册、已登录绑定与本次绑定成功分别展示；未向服务器查询的历史绑定状态不会显示为“已绑定”。
- `pages/login/index.wxss`：独立页面样式，品牌深绿、青蓝主按钮、浅绿辅助按钮及白色卡片；375px 参考宽度下左右留白 16px、卡片圆角 12px。原生导航栏处理顶部胶囊，底部使用安全区域，小屏和注册长表单自然滚动。按钮触控高度至少 44px，输入区域至少 48px。
- `pages/login/index.json`：浅色原生导航栏，保留现有路由。
- `pages/login/index.js`：密码显隐、手机号清空、字段校验、注册确认密码、提交状态和重复操作拦截；后台隐藏密码，页面卸载忽略迟到响应，切换身份清除原绑定确认。登录成功自动返回来源页面，失败时回退“我的”；直接进入登录页时回到“我的”。游客可直接前往首页。
- `tests/login.test.cjs`：14 项行为测试；`tests/helpers.cjs` 增加页面栈模拟。

手机号密码登录是主要入口，因为当前微信登录只支持已经绑定的账号。登录成功不强制停留绑定页面；微信绑定继续通过“我的 → 账户设置 → 绑定当前微信”进入。绑定成功保持完成提示，用户自行返回原页面。

注册密码沿用服务端规则：8–64 位，含大写字母、小写字母和数字；登录只检查长度，不给历史密码额外加复杂度限制。切换注册/登录保留手机号并清空密码；注册成功回到登录表单，不伪造会话、不保存密码。错误提示保留真实接口信息，纠正输入可清除提示。

## 接口兼容

| 接口（相对 `config.js` 的 apiBase） | 请求 | 行为 |
| --- | --- | --- |
| `POST /users/login/password` | `{account, password}` | 原有消费者登录，验证有效 token 后存储会话并返回 |
| `POST /users/register` | `{phone, password, nickname}` | 真实注册成功后返回登录表单；昵称为空传 null |
| `POST /auth/wechat/login` | `{code}` | code 来自 wx.login；未绑定或未配置时展示服务端错误 |
| `POST /users/me/wechat-binding` | `{code}`，原消费者 token | 服务端确认后才显示本次绑定成功；不切换消费者身份 |

这些接口不是列表接口，无分页。网络失败、业务错误、无效登录返回均不展示成功。没有接入短信登录、微信手机号授权、密码找回或新增协议内容；登录帮助说明现有账号和微信绑定的使用方式，不编造客服电话。员工工作台的独立登录方式沿用原实现。

## 运行与可复现预览

1. 微信开发者工具导入 `miniprogram/`，沿用项目 AppID，配置可访问的后端地址和合法域名。
2. 自定义编译启动页设为 `pages/login/index`，或清除消费者会话后点击“我的 → 登录 / 注册”。游客预览和注册表单不依赖后端。
3. 在 320、375、414px 宽模拟器检查卡片、手机号键盘、密码显隐、错误提示、注册长表单滚动和底部安全区域；键盘展开后应能滚动操作。当前这些视觉、键盘及真机项目仍需人工验收。
4. 从购物车进入登录，验证登录成功返回购物车并由原页面刷新数据；直接编译登录页时成功回到“我的”。
5. 从“我的 → 账户设置 → 绑定当前微信”进入绑定页，验证成功、已绑定其他账号、登录过期、服务未配置等状态；重新打开页面不凭本地记录猜测服务端绑定状态。
6. 注册使用服务端允许的测试手机号，检查弱密码、两次不一致、重复手机号、成功返回登录；检查已绑定微信登录及未绑定时密码登录可继续使用。
7. 后端断开后提交，检查错误反馈、加载结束和重试；快速重复提交只有一个请求，操作中不能切换模式或改写表单。

```powershell
cd miniprogram
npm run check
npm test
npm run check:wechat
```

实际自动验证：静态检查通过；微信原生编译器通过 15 个 WXML 页面和 7 个 WXSS 文件；全量测试 100 项，99 通过、1 项原有图片服务符号链接测试因 Windows 权限跳过，其中新增登录测试 14 项全部通过。

当前未运行开发者工具 GUI、真实账号接口联调或微信真机检查，没有实际优化前后截图；以上启动路径用于复现预览。原生编译及模拟接口测试不等同于视觉、键盘或真机验收通过。

## 外部接入事项

本轮已实现页面和现有登录链路的客户端优化，无演示成功流程。实际密码登录/注册需要可访问的原后端；微信登录/绑定需要服务端真实 AppID、AppSecret、微信配置和相应已绑定账号。凭据仅配置于服务端。

若后续增加找回密码、短信/微信手机号登录或协议勾选，需要先提供对应真实接口、运营联系方式与正式用户协议/隐私政策；本轮没有用不可用按钮或虚构协议代替这些能力。
