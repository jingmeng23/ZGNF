# 自贡能发微信小程序

微信原生客户端，共用现有商城后端。使用微信开发者工具导入本目录，在 `project.config.json` 填入自己的 AppID，在 `config.js` 配置 HTTPS API 和图片域名。

首次使用网站已有的手机号密码登录，再绑定当前微信。订单支付使用服务端签发的微信支付参数，最终结果以官方回调/后端查单为准。

完整配置、接口、退款和验收步骤见 [微信小程序与支付开发说明](../docs/wechat-mini-program.md)。

运行 `npm run check` 检查页面路由和脚本，`npm test` 运行支付客户端测试。检查不替代微信开发者工具编译、域名配置和真机支付验收。
