# 移除门店管理

当前商城不再提供门店管理、员工归属门店、库存分仓、工单门店选择或门店统计。

- 员工保留部门、岗位、角色、启停用与密码管理。
- 工单直接派给启用且具有 `workorder:process` 权限的员工；本人处理权限、状态流转和未完结工单保护继续生效。
- 库存为商城统一库存。保留旧库存档案 ID、数量、锁定数量、流水及订单预占关系；同商品历史多行库存继续按行维护，订单汇总可用数量并精确释放、扣减原预占行。新建接口禁止重复商品建档。
- 商品、购物车、订单、支付、优惠券、售后及其统计沿用现有流程。

新增 Flyway 迁移 `V1.28__remove_store_management.sql` 删除门店资料表、相关权限及授权、独立门店操作日志、关联字段，并从派单日志中移除门店标识。历史已执行的迁移文件保留，避免校验和变化或新数据库初始化失败。业务历史及库存不会因移除模块而删除。

升级需同时使用新前后端。先备份数据库，停止旧后端写入，再启动新后端自动执行迁移。迁移删除的表与字段无法通过回退程序恢复，恢复时须同时恢复升级前的数据库与程序。

验证包括全量后端与前端测试、前端构建、员工页面浏览器冒烟测试，以及 MySQL 数据副本上的迁移验证。`StoreRemovalMigrationTests` 覆盖移除表和字段、权限清理、历史流水清理、旧订单释放/扣减及旧工单继续处理。
