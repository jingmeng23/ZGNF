# 购物车升级与验收记录

验收日期：2026-11-13。沿用 Vue 3、TypeScript、Pinia、Vue Router、现有商城 API 和 Spring 业务服务。未部署上线。

## 访问方式

- 购物车：`/#/cart`，登录入口：`/#/login?redirect=/cart`。
- 商品详情：`/#/products/:id`；地址：`/#/addresses`；优惠券：`/#/coupons`；订单：`/#/orders`。
- 本次本地开发服务：`http://127.0.0.1:5181/#/cart`。服务关闭后可在 `frontend` 运行 `npm run dev`，按终端实际端口访问。
- 沿用真实账号、服务和登录机制；浏览器验收脚本自行注入的测试会话与接口响应不会进入产品页面的数据源。

## 已实现

- 1280px 内容区、白色卡片、浅灰背景和砖红色按钮；桌面商品列表与 312px 订单汇总并排。较窄或较矮屏幕不使用汇总吸顶。
- 手机采用纵向商品卡片、固定全选/金额/结算栏，优惠与金额明细可展开，正文预留底栏与安全区空间。
- 商品图片完整展示、加载失败占位、真实价格和数量、小计、商品详情链接、真实收藏接口；移除虚构店铺、权益和无意义规格下拉框。
- 明确区分商品种类与总件数，商品全选、单选和半选只计算可购买条目。失效商品独立展示，删除所选与清理失效商品分别确认实际影响条目。
- 数量加减、直接输入、整数/库存/999 上限校验、防抖、购物车写入串行化；失败后读取服务端状态，金额、购物车角标和汇总同步更新。旧登录会话响应不会覆盖新会话状态。
- 读取全部购物车分页；删除按显式 ID 分批提交，每批最多 100 条，保留 Long 字符串精度。未提供虚假撤销。
- 地址、满减、运费、单张订单优惠券接入服务端报价。优惠面板展示门槛、到期时间与不可用原因；选择变化后重新校验；未知运费明确提示选择地址后计算。
- 同步或报价未完成时停止结算，报价失败提供重新计算与刷新购物车。金额比较和演示模式计算使用整数分，展示复用 `formatPrice`。
- 结算前重新获取全量购物车，检测价格、数量、库存及选中状态变化，核对报价商品集合；确认弹窗显示应付金额，确认后调用现有真实订单创建接口。
- 失败保留用户选择并复用同一结算票据重试；阻止重复提交。创建订单成功后的购物车刷新失败不会被误报为订单创建失败。
- 原生对话框支持 Escape、键盘焦点约束及关闭后恢复触发按钮。加载、未登录、空车、失效商品、请求失败均有对应状态。
- 后端全选只勾选当前可购买商品，并清除历史失效选择；失效商品不能被单独重新勾选，但可以取消选择。

## 真实模型仍不支持的能力

1. **店铺分组与店铺选择**：当前购物车条目没有店铺 ID，不按名称猜测或虚构店铺。需后端提供稳定店铺 ID 后实现分组及店铺半选。
2. **修改规格与 SKU 合并**：当前购物车写入只接收商品 ID、数量；条目没有 SKU ID/规格组合，商城 SKU 商品也没有可用加购契约。本次显示默认规格文本，未提供虚假的修改或合并行为，也未声称验证该流程。
3. **店铺券、平台券叠加及特殊购买限制**：当前仅有订单通用优惠券和单券结算契约。按服务端现有按件步长 1、单条上限 999 与可用库存校验；自定义步长、SKU 限购和店铺券范围需扩展接口及规则。
4. **真实服务权益**：购物车没有权益字段，不添加包邮、价保、赠品、退换承诺或空入口。运费由地址和服务端配送规则确认。
5. 本次浏览器验证使用拦截响应，未执行生产账号的真实支付、外部支付渠道、真实物流或手机设备实机验收；这些不能由本次截图或自动化结果替代。

现有接口足以完成商品级购物车、地址/优惠报价及创建订单；没有新增另一套真实购物车数据源或模拟交易成功的产品逻辑。
